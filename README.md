## Git Quick Reference

| Command | What it does |
| :--- | :--- |
| `git status` | See what's changed |
| `git add <file>` | Stage a file for commit |
| `git commit -m "message"` | Save staged changes |
| `git push -u origin master` | First time - set upstream |
| `git push` | Upload commits to GitHub |
| `git pull` | Download changes from GitHub |
| `git log --oneline --graph` | View history as a tree |
| `gitk --all` | View history graphically |
| `~/go/bin/gitk-go` | View history graphically (Modern Style)|
